# 结构资料与夜间模式

结构资料由 `0.5.0-structure` 加入；当前入口以 [连续时间线](TIMELINE_TRACKS.md) 与 [直接编辑](TIMELINE_EDITING.md) 为准，以现有自由详述为基础，不自动解析旧资料，也不新增模型 API 或后台扫描。

## 作者入口

- **设置 → 外观 → 夜间模式**：跟随环境、浅色、深色，立即生效并按设备保存。跟随环境优先用宿主主题，独立调试页面则跟随系统。
- **设定详情 → 资料字段与章节关联**：编辑角色／世界可选字段。别名共用原资料的别名数组；名称与正文仍从原编辑器修改。
- **管理字段模板**：按本作品、卡片类型维护字段，支持短文本、长文本、数字、标签、资料引用。改名保留稳定 ID，归档保留值，可恢复。为避免旧值被误解释，创建后不能改变字段类型；需要另一类型时建立新字段。
- **正文 → 本章资料**：可选中已保存正文再打开入口，或手填原文依据。角色关联分实际出场、仅被提及；世界资料使用资料关联。手机显示整页资料面板，电脑显示工作台内资料窗口。
- **角色卡章节记录**：显示首次实际出场、首次提及和依据，可跳转正文。首次按卷顺序、卷内章节顺序计算，使用稳定章节 ID；删除章和删除资料从当前汇总排除，历史引用保留。正文内容哈希变化提示复核，纯改名或调序不误报正文变化。
- **概览**：正文总字数、章节数、分卷汇总、分章字数和可选目标。含标点、不计空白，排除设定、历史、删除章。首版无每日统计。
- **时间线 → 伏笔筛选／就地编辑**：计划、已埋设、推进中、已回收、已放弃；记录埋设／推进／回收原文与版本、计划回收章、人物与世界关联。埋设需要埋设依据，回收还需回收依据，放弃需原因。计划回收章已写入正文、或当前查阅章到达该位置时提示待回收。正文改写提示复核。
- 字段和伏笔有旧版本恢复；恢复仍检查当前版本。章节关联软删除且保留历史，工具可恢复。保存失败不丢当前编辑草稿，错误在编辑页内显示。

## AI 接口

`workbench_query` / `workbench_edit` 增加 `writing.*` 操作：

| 查询 | 写入 |
| --- | --- |
| `writing.fields.list`、`writing.card.get` | `writing.field.create/update`、`writing.card.update` |
| `writing.link.list/candidates` | `writing.link.create/delete` |
| `writing.stats.get` | `writing.goal.set` |
| `writing.foreshadow.list`、`writing.history` | `writing.foreshadow.create/update`、`writing.restore` |
| `writing_context.get` | — |

所有操作明确指定 `novelId`。卡片字段修改以字段记录 `expectedRevision` 检查，别名修改还携带 `expectedNodeRevision`。章节关联携带 `expectedChapterRevision`，依据必须存在于此已保存正文版本中。出场与伏笔记录必须 `confirmed:true`，仅代表作者明确确认或要求记录，不得把 AI 推测自动保存为事实。客户端写入不自动重试，调用方可提供稳定 `requestId` 去重。

`writing_context.get` 按 `chapterId` 与可选 `nodeIds` 返回关联资料、字段、首次记录与相关伏笔，默认最多 12000 字符，可指定 `maxChars`（2000～24000）；超过容量减少条目并标记 `truncated`。不自动加载全书正文，创作要求仍按需读取 `preset.read`。时间线和阶段关系已在 0.6.0 接入，可指定 `eventId`，详见 [时间线说明](STORY_EVOLUTION.md)。

## 保存、导入与回退

可选扩展保存于作品 `writing`，基础扩展兼容格式版本 1；保存整理候选后使用版本 2，新版同时支持两者；旧作品不自动填值。完整作品 JSON、完整工作库备份和恢复保留扩展及历史。复制整部作品会重新映射资料、章节、字段和伏笔 ID。局部导出保留所选资料字段；不在范围内的结构引用或不完整伏笔省略并在预览说明，完整备份保留全部。新字段类型或扩展格式未知时拒绝恢复，避免错误解释数据。

代码回退与作品恢复分开：部署前私有 SQL 备份在本地忽略目录；另上传旧稳定界面、但仍支持结构资料的新服务版本作为兼容回退。不要把旧业务引擎覆盖部署到含结构资料的新作品库，也不要用旧备份替换最新作品来回退界面。

当前验收覆盖虚构作品、手机宽度、浅深色切换与重开、字段保存、关联跳转、回收验证、原项目／本地／D1 回归。安卓实机键盘、触控与宿主聊天同时显示需作者验收后打发布标签。原有自由详述 Markdown 阅读与基础连线分类已完成；时间线及关系演变见 [时间线说明](STORY_EVOLUTION.md)。
