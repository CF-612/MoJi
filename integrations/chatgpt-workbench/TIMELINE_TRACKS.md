# 连续时间线（0.9.0）

时间线保持竖向。章节顺序与故事时间通过切换显示，不同时画两条轴。

章节顺序使用正文章节作为刻度；同一个事件只画一条范围条，跨越其首尾关联章节。圆点标出真实引用，中间的空缺不会自动变成事件引用。重叠范围放在不同轨道，手机可以上下、左右滑动。没有事件的章节只显示卷章标题与快捷添加入口，不生成空事件卡。

每章显示已关联的共享规划卡片，带名称和状态颜色。可就地添加、编辑规划或创建事件，仍与情节画布共用同一记录。故事时间视图按明确事件顺序排列，保留倒叙与插叙的独立叙述顺序；它不是按真实时间间隔比例绘制的日期轴。

“全部、事件、人物、伏笔”筛选只改变显示。人物标记使用已确认的出场或提及；故事视图中的参与、进入故事不自动证明正文出场。伏笔的埋设、推进、回收和计划回收在同一图中展示，未指定位置时进入待安排区域，取消独立台账入口。编辑和历史恢复保留原接口及记录。跨章事件与伏笔都不会被复制成多张记录。

点击事件，或移动“浏览位置”滑块，切换当前阶段关系。浏览没有新事件的章节时，沿用此前已确认事件的关系；长事件继续跨章不会重新覆盖后续事件阶段。计划事件只有被明确选中时才预览计划情境。浏览动作只保存设备上的游标，不写作品、引用或关系。

窄容器使用显式“当前时点关系图”入口，电脑并排展示。关系图支持原有平移、缩放，并增加可见的新建角色/世界入口及右键菜单。新资料仍存入设定库；事件进入位置通过已有“关联资料”指定，不能自动确认出场。

新建卷和章节预填可编辑的“第X卷/第X章”。章编号按所属卷独立计算，已删除编号不自动复用；更换所属卷时，只更新仍未被作者修改的默认标题。番外可以直接删除前缀。现有标题、正文和导入内容不批量改写。

AI 调用沿用现有操作：`writing.event.create/update` 的 `chapterRefs` 表示同一事件的多个呈现位置；规划、出场、伏笔及阶段关系共用原接口。`volume.create/chapter.create` 不提供标题时生成默认编号；指定标题默认原样保存，可用 `autoNumber:true` 为普通标题添加前缀，已有“第X卷/章”不会重复添加。普通阅读和新建 UI 无需新增工具名称。

无需作品数据迁移。回滚界面时保留兼容当前作品版本的后端，作品备份与代码回退分开处理。
