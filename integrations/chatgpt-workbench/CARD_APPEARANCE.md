# 卡片颜色与快捷设置

本批云端版本：`0.4.2-cards`。

- 角色卡默认紫色左侧色带；世界书默认青绿色顶部色带。列表与画布使用同一配色，保留类型文字和图标。
- 规划卡默认蓝色（讨论中）、橙色（准备采用）、绿色（已写入正文）、灰玫瑰色（暂不采用）。画布缩小后色带和状态标记仍可见，选中框不替代状态色。
- 「设置 → 卡片颜色」可以选择六类颜色，单项可重置。卡片的快捷设置也提供对应颜色入口。
- 颜色是按设备保存的显示偏好，适用于本机同类卡片，不修改作品数据，不随作品 JSON 备份同步。清理浏览器存储或更换设备后恢复默认色。
- 每张设定或情节卡的外侧有齿轮按钮，列表和画布均可直接打开「卡片快捷设置」。桌面右键菜单也有这个入口。
- 设定可修改类型、分组；规划可修改进展、分组。缺少正文依据的规划切换成「已写入正文」时，需要明确选择实际写入的章节，保存该章节版本引用。已有引用保留。
- 快捷修改只提交相应属性，使用打开面板时的版本号检查冲突。不会覆盖正文、画布位置或关系。冲突时面板保留尚未保存的选择；关闭后重开可取得最新属性。
- 完整正文、故事线、关联资料等仍从「打开完整详情」修改。已有完整详情草稿保持原版本基准，不会被快捷修改静默覆盖。

本批未改变作品数据格式，可回退到上一稳定的 `0.4.1-mobile` 界面和服务，保留最新作品数据。

验证包括隔离虚构作品的手机宽度布局、50% 画布、颜色重开保留、快捷类型/进展保存、浅深色预览，以及业务与云端回归。安卓实机手感与宿主面板仍需作者验收后再打发布标签。
