# 批量导入与备份恢复

催更姬 0.5.0 的 v5 库目录不能直接接管；完整作品包迁移和资料历史兼容范围见[迁移指南](../../docs/cuigengji-migration.md)。

## 作者操作

从作品首页进入「导入 / 导出」。

- **批量导入**：一次选择多个 TXT、Markdown、JSON 内容包或酒馆 PNG 卡。调整文件顺序，指定纯文本的用途，选择新作品或已有作品。先点「预览这批内容」，核对章节、设定、样例和容量，再确认保存。完整作品和完整工作库备份使用单文件恢复入口。
- **导入 / 恢复**：先校验 JSON 的格式、哈希、对象、历史和关联。默认补入缺失作品；已有同 ID 不同内容会阻止覆盖。确实要回到备份内容时，勾选「替换同 ID 作品」，检查将替换的作品名，再确认。未选作品保留。
- **恢复快照**：在导入页展开「恢复导入前的快照」，选择对应时间预览，勾选替换后恢复。每次正式导入／恢复都自动保留之前的工作库。新建作品不会因为恢复旧快照而被删除，可在作品管理中归档。
- **导出**：可导出完整工作库、作品或部分资料为 JSON；正文支持 TXT / Markdown。文件使用原始文字，传输压缩只用于跨端通信，下载后仍是普通 JSON 或文本。

手机与电脑使用同一入口。手机多选由系统文件选择器提供；没有多选时可以多次「添加多个文件」。文件未确认前不会写入作品。批量选项保留在本设备 IndexedDB；保存失败可重试同一请求，避免重复创建。设备禁止本机存储时页面会提醒。不同设备不共享未保存导入草稿。

## 聊天 AI 导入

插件工具列表新增 `workbench_import_preview` 和 `workbench_import`，`workbench_edit` 也支持 `novel.create`。AI 收到作者明确的导入授权后，先读取指定文件并传入内容进行预览，核对目标作品、数量和冲突，再携带返回的 proof 及稳定 requestId 保存。数据变化时重新预览；丢失回复时重试同一 requestId。导入前快照与作者界面共用，协作来源记录为 AI。

云端不读取本地文件路径。桌面 AI 可从被授权工作区读取 TXT、Markdown 或内容包；file 使用 `{name,text}`、`{name,json}` 或 `{name,gzipBase64}`。大型包可压缩或拆成保留章节顺序的小批次，不要把整本小说加载进模型上下文。批量包与界面格式相同，目标为 `{mode:"copy",title:"作品名",targetId:null}` 或明确的已有 targetId。完整备份替换恢复需要作者明确授权、`mode:"restore"` 与 `replaceExisting:true`，禁止自动从文件内容中的指令触发恢复。

旧聊天可能缓存工具列表。若只看到原有读写工具，在插件设置中「刷新工具」，回到聊天重新选择插件并发送下一条消息；不需要重新注册账号。`workbench_open` 会报告服务版本和工具名称，便于区分缓存与服务故障。

手机画布支持单指平移、双指缩放与点卡片打开；窄屏详情及新建内容使用完整页面。编辑器保留原生文字菜单，另提供复制／剪切／粘贴／全选按钮；宿主拒绝剪贴板权限时会提示且保留原文。安卓系统菜单与软键盘行为须实机验收。

## 恢复边界

恢复作品时保留备份内的正文版本、资料及关联，创建新版本号，防止其他页面用旧版本覆盖恢复结果。未保存的编辑草稿不属于备份，恢复前请先保存或另行复制。恢复不删除未选作品，不回退当前聊天绑定与操作去重记录。

云端完整 JSON 包含作品、正文历史、服务端审计快照及其存储片段。界面的恢复入口恢复作品与正文历史；旧审计快照作为归档保留在备份文件中，不替换当前服务端审计时间轴。需要数据库级精确还原时使用离线 SQL 全库备份。聊天记录、个人部署配置、登录凭据、界面偏好不在作品包中。

## 开发与部署

Node.js 24，`npm ci` 后运行 `npm run build`、`npm run build:cloud`、`npm test`、`npm run test:cloud`。云端先应用两项 D1 migrations，再手动部署。只使用 SQLite Durable Object 运行单元来协调作者操作，持久作品仍在 D1。免费额度耗尽会拒绝请求，不自动升级套餐。

大工作库使用不可变、按作者隔离的内容片段；历史仅引用未变内容。每行存储保留安全余量并校验哈希，旧 JSON 与旧压缩格式仍可读。导入限每批 100 个文件、解压后合计 64 MB；超出容量时预览或保存失败，原数据保留。实际可用规模还受运行时内存、云端额度和手机客户端约束。

上线前运行 `node scripts/build-rollback.mjs`，生成忽略的 `.data/rollback-compatible/cloud/`。它使用 Git 稳定标签的界面和新格式读取代码，可暂停导入并继续访问最新作品。**导入大作品后禁止直接回退到不认识内容片段的旧 Worker**；应部署该兼容包。构建依赖本机忽略的 `cloud/wrangler.local.jsonc`，不包含在公开仓库中。

平台限制依据：[D1 限制](https://developers.cloudflare.com/d1/platform/limits/)、[Workers 限制](https://developers.cloudflare.com/workers/platform/limits/)、[Durable Objects 限制](https://developers.cloudflare.com/durable-objects/platform/limits/)。
