# 时间线折叠与阶段变化 0.8.6

手机专注写作模式后移。本批完善已有时间线、关系和资料的阅读联动，不增加新的资料类别或独立台账。

## 长时间线

- 章节轴按卷、章折叠，默认展开当前卷章；提供“只展开当前”“全部展开”及卷章／事件跳转。
- 切换上一个／下一个节点时会展开目标所在区段，包含原先折叠的节点。空章仍可进入本章规划，跨章呈现的事件保持不同章节位置。
- 故事轴只合并连续的相同故事时间区段，不把分散的同日期事件聚在一起，不猜日期间隔、不改变已保存排序。
- 仍只显示一条竖轴。展开、收起、切换、跳转仅使用已读取投影，不保存作品或加载正文全文。

## 本节点变化

- 单独显示当前事件中首次进入故事的角色／世界资料。进入位置不替代已确认正文出场。
- 关系显示前一故事阶段与本事件状态，包括新增、名称／类别／线型／说明变化及结束。比较使用故事先后，不使用作者上一次点击的节点；已删除变化和未确认计划按既有阶段规则排除。
- 关系图突出进入资料和发生变化的连线。在结束节点显示淡色“结束”线，便于查看结束前关系及编辑其变化；后续节点不保留这条结束提示线。
- 伏笔埋设／推进／回收依据标为“本章伏笔依据”；同章有多个事件时不推断它们的先后。没有正文依据的事件关联仅标为关联伏笔。依据变化继续提示复核。

## AI 与验证

既有 `writing.stage.get` 返回新增 `changes`：previousEventId、planned、entering、relationships（before/after、kind、contentChanged）、chapterForeshadows 及 eventForeshadows。只读结果不含历史全文，复用同一批已保存记录。写入仍通过已有版本接口及作者确认；本批不增加模型调用、后台扫描或自动认定事实。

测试覆盖卷章／空章／跨章折叠、连续时间段与倒叙、已删除与计划隔离、关系新增／更改／结束、无变化、进入与出场区分、伏笔整章依据及只读不改变作品。实际 Worker 的 MCP 路径验证 changes 可读。内置浏览器验证 390px、折叠章节跳转、切轴、关系结束、深色和桌面图；安卓实机仍需实际使用确认。

本批无数据结构迁移。部署前保留源码 bundle、上一版稳定界面与部署标识，回退界面不恢复或覆盖最新作品数据。手机专注模式、AI 整理结果统一预览、版本差异高亮和统一搜索留待后续。
