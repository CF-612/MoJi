# 版本差异高亮 0.8.7

正文历史比较、正文冲突比较、规划修改记录与远端比较，以及资料字段／事件／关系变化／伏笔的历史比较使用统一阅读组件。手机专注模式仍后移。

- 红色“−”标删除，绿色“＋”标新增；较小的替换块进一步高亮具体文字。包含 Markdown 源码、换行和空白，不渲染或执行源码中的 HTML。
- 默认收起未变化内容，可单独展开或选择“显示全文”。规划记录只在展开比较时计算差异，不同时计算整页历史。相同内容明确显示一致；两份完整原文均保留。
- 比较按行匹配，矩阵和逐字比较都有计算量上限。大范围改写降级为文本块，明确标注块统计，不为精细匹配阻塞手机。
- 字符数量按 Unicode 字符计数，包含换行与空白；精细高亮可用时只统计高亮字符，块比较按完整变化块统计。不是正文有效字数或每日写作统计。
- 结构资料比较使用字段名和已保存记录，忽略版本、时间与来源等审计元数据。保留已归档值、数值 0、关系结束状态及正文依据；同名资料引用加标识区分。
- 正文合并编辑保留在比较页的“编辑本地合并内容”中，仍通过原自动保存和冲突处理流程。阅读、展开或关闭比较不保存或恢复内容。
- 结构资料历史增加“比较这版”；本地有修改时明确标为草稿，仍禁止直接恢复覆盖草稿。恢复／撤销按钮及版本检查沿用现有机制。

## 范围与验证

自由角色／世界详述尚无独立历史比较入口，本批覆盖其可选字段历史。写作要求也未增加独立版本台账；不从缺失的历史猜测旧内容。

测试覆盖双方原文重建、中文、emoji、重复行、CRLF、空白、无尾换行、随机增删、大段降级、字段元数据、同名引用及 HTML 转义。内置浏览器以虚构资料检查手机正文历史、字段比较、全文切换、深色及页面宽度。安卓实机仍需实际使用确认。

本批不增加依赖，不改变业务数据结构、存储、历史或恢复接口。保留上一稳定界面和源码 bundle，界面回退不恢复最新作品。AI 整理结果统一预览和统一搜索仍属后续计划。
