# 事件直接编辑与后台位置保存

版本：0.9.3-timeline-direct-edit。

事件条本身提供“设置”按钮，桌面双击和触屏长按也打开同一事件编辑页。单击继续选择阶段；移动与首尾手柄只调整位置，不再自动打开位置确认弹窗。长按移动超过 8 像素、抬手或取消后不触发编辑，保留触屏滚动。

新建事件只需保存，名称为空时使用“未命名事件”。说明、时间、角色、规划、伏笔和章节依据都可稍后补充。编辑页提供“删除事件”；删除需要一次确认，保留历史恢复入口，关联关系变化不再应用于当前阶段。

拖动松手即更新本机预览并排队后台保存。后续拖动不会等待前一次请求，也不使用页面全局忙状态。每次意图保留原读取版本和固定请求 ID；只接续本队列已确认的版本增量。网络失败、丢失响应或跨端冲突保留本机位置草稿，不自动采用外端版本覆盖。重开后明确重试，仍使用已发送的原参数。放弃草稿重新读取云端，不撤销可能已成功但响应丢失的写入。

打开事件内容编辑前等待当前位置队列完成，避免内容保存与位置保存互相覆盖。失败时可重试或放弃位置草稿再编辑。旧版本已有的位置草稿保留“继续调整”入口，但不自动弹出。

回归包括实际事件条处理器、长按取消、连续移动及缩放范围、故事顺序与章节叙述独立、丢失回复后的相同请求重试、跨端冲突、占位事件补充和删除历史、本机 Worker 授权与 UI 资源。桌面浏览器实际绘制及 Android 真机手势未在本轮验证。

公开 Git 仅保存源码及虚构测试。上一稳定源码、构建和云端作品导出保存在忽略的 `.data/pre-direct-event-edit/`。代码回滚不恢复旧小说数据；本轮不改变数据结构或权限配置。
