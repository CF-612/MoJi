# 内置模块骨架与白板保存

本批版本：`0.9.2-module-foundation`。

## 模块显示

设置 → 工作台模块提供极简、标准、完整预设，以及创作仪表盘、时间线、伏笔辅助和关系演变的单独开关。旧设备偏好缺少模块字段时全部开启；正文仍是第一个入口。

当前开关是按设备保存的界面偏好，不是实例的业务禁用或安全权限。隐藏模块不删除数据，也不禁止已授权的 AI 查询与修改。权限、真正卸载模块代码和第三方插件安装留到后续，不能以隐藏按钮替代服务端校验。

关系演变依赖时间线：开启前者会显示时间线，关闭时间线会同时隐藏关系演变。关闭伏笔辅助会隐藏章节联动、时间线轨道和仪表盘中的对应入口。搜索等入口定位到隐藏页面时提示到设置重新显示，不静默丢弃资料。

## 代码入口

- `vendor/cuigengji/src/client/modules/registry.mjs`：稳定 ID、说明、依赖、预设和导航规则。
- `modules/context.tsx`：页面共享显示能力，独立于设置页面和宿主代码。
- `modules/index.tsx`：设置视图与扩展页面装载。
- 业务层继续处理版本、历史、引用和写入校验，不为每个视图建立第二份记录。

新增页面先登记模块和装载入口，再实现模块内容及联动。装载采用延后渲染接口；当前单 HTML 构建仍打包代码，不宣称支持独立下载或物理卸载插件。

## 白板布局

规划画布和设定关系图使用共用 `shared/layout-queue.mjs` 保存坐标。

- 拖动立即更新本地位置；暂停操作约 1.2 秒后合并保存。
- 后台请求期间可继续移动，下一次保存使用已确认版本。
- 离开画布或页面隐藏时尽力提交。关闭浏览器时不依赖请求必定完成，而是保留本机位置草稿并提示尚未保存。
- 一批最多 200 个坐标，更多坐标分批处理；同一卡片只保留该批最后位置。
- 重试保留已发送请求的参数及 ID，较新的移动留在后续草稿中。
- 冲突不自动更新基准。明确确认后可保留目标、按当前已读取版本重存；已删除卡片不能强制重存。
- 放弃位置草稿不删除卡片，也不承诺撤销可能已成功但响应丢失的远端请求。

布局保存不使用页面级全局忙状态，不为每次鼠标移动写服务器。正文及其他内容修改保持原有保存规则，本批没有把所有内容推迟到关闭页面才保存。

## 图表修复

旧全局 SVG 圆点样式覆盖仪表盘的填充、线宽及颜色。图表色段现在显式标记并避开该样式；零目标进度显示浅色底环，空伏笔图显示等待状态，不填灰色实心圆盘。

## 验证边界

回归覆盖模块依赖与旧偏好、真实时间线渲染、SVG 色段、真实画布指针处理器、布局合并、后台再次移动、恢复重试、冲突重存和本地 Worker/D1。

本批浏览器验证通道被自动审批拒绝，因为用户要求不用 Computer Use；未绕过该限制。浏览器实际绘制、Android 真机手势和设置布局仍需复测，不将静态渲染及指针处理器测试等同于真机验收。
