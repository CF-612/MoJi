# 统一工作台入口

日常创作只使用一个「催更姬 · 小说工作台」远程插件。电脑 Codex、网页版及手机 ChatGPT 都连接同一私有云端业务服务，使用同一套界面与作品记录。后续界面更新由云端手动发布，不另维护一套桌面旧版。

## 旧入口处理

- 先备份本地数据目录，验证备份能够解压并读取作品目录；原目录保留。
- 保留已完成登录、能返回当前版本的正式插件。
- 停用早期本地演示插件、重复的旧远程插件和单独添加的同地址 MCP 配置。停用只改变入口启用状态，不删除作品或撤销正式插件登录。
- 重新读取插件安装状态，确认正式插件启用、旧插件停用；再次调用正式插件，确认当前版本及原作品仍可读取。
- 记录变更前的启用状态，便于重新启用旧入口。个人状态、插件实例 ID、登录配置和数据备份都放在忽略的 `.data/`，不提交到公共仓库。

本地演示作品不会自动混入正式云端目录。需要迁移时先导出，再用现有导入预览判断新建或合并，确认后保存。

## 使用与恢复

从聊天中选择正式「催更姬 · 小说工作台」并打开；旧的已渲染卡片或页签可能仍显示旧内容，关闭后使用新打开的卡片。若当前客户端仍显示停用入口，重新启动客户端以刷新已加载的工具目录。

本地的源码、备份与手动导出仍保留。开发使用 `npm start` 的本机演示服务，不代表另一个正式作品库。

代码回滚使用兼容最新数据结构的上一版界面；作品恢复使用带预览和版本校验的恢复入口。不要直接用旧业务层写入新作品。

## 离线边界

会话缓存只用于减少切页等待；正式读写仍通过云端。当前没有断网编辑后自动双向同步功能，不能把“统一入口”当作已实现离线副本。电脑关机后，手机仍可访问云端作品。
