# 统一规划视图

0.9.5 将规划收为“时间线／画布”两个视图。顶部独立“时间线”导航和普通规划列表切换删除；批量管理仍使用勾选列表。时间线模块设置控制规划中的时间线能力，不再增加一个顶级页面。

两种视图共用当前规划页面、分组、搜索和状态筛选，读取同一份分批完整的规划快照。切换视图不重新加载这份快照。卡片 ID、版本、内容、连线和画布坐标不改变，不复制旧资料。

章节顺序显示直接关联章节的规划，以及关联该章事件的规划。故事时间显示事件关联的规划。未出现在当前轴上的卡片显示在“待安排规划”；仅关联已删除章的规划也保留待安排入口。两轴仍单独切换显示，事件跨章长条和关系演变继续保留。

时间线上已有规划打开与画布相同的完整详情。新规划继承当前页面和分组；无时间关联时进入待安排区。工具栏也可以直接创建未安排规划，之后再关联章节或事件。两种视图的新建草稿使用相同本机缓存键。

旧列表默认视图映射为时间线；已保存的画布偏好保留。旧顶级时间线位置、章节／搜索／资料中的事件跳转统一进入“规划 → 时间线”。源码与业务数据的备份、导出、冲突和恢复机制保持不变，AI 动作名称与参数也不改变。

验收使用虚构卡片验证两轴都保留完整当前页面、事件规划落在对应章节、同 ID 编辑没有复制数据，以及原有模块、批量、导入恢复、事件拖动和云端鉴权。Android 真机布局仍需要实际使用复核。
