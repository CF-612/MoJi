# Markdown 阅读 0.8.4

角色卡、世界书、规划、长文本资料字段、关系说明、事件／伏笔说明和写作要求支持 Markdown 阅读及源码／预览切换。正文继续使用现有编辑器，章节依据保持原文，姓名、类别及关系名称保持普通文本。

## 阅读与保存

- 支持标题、强调、删除线、嵌套列表、引用、任务列表、表格、代码块、链接及脚注。任务框只展示已记录状态。
- 切换源码／预览不触发修改或保存；保存、AI 读取、历史、导出与复制仍使用原始文本。写作宏保留，预览不执行宏替换。
- 阅读不执行原始 HTML。脚本、文件及相对接口链接不可点击；普通外链使用独立窗口及 noopener/noreferrer。Markdown 图片以需主动打开的链接展示，阅读资料不自动请求外部图片。
- 宽表格和代码块在自身区域滚动，不挤宽手机页面。浅色／深色共用已有主题变量，文字编辑沿用原复制、粘贴及草稿机制。
- 无数据结构迁移，不重写已有卡片。退回前一界面仍能读取保存的 Markdown 源码，作品数据无需恢复。

## 实现与验证

使用固定版本 [react-markdown 10.1.0](https://github.com/remarkjs/react-markdown) 和 [remark-gfm 4.0.1](https://github.com/remarkjs/remark-gfm)。保留 React 元素渲染，不启用原始 HTML 插件，不增加语法高亮依赖。

测试覆盖常用语法、脚本／图片隔离、CRLF／尾部空白／宏的原文存储，以及资料、规划、关系、写作要求和完整备份复制往返。内置浏览器以 390px 检查资料阅读、源码往返、一次点击保存、深色显示、表格宽度和写作要求预览。安卓实机长按、软键盘仍由作者实际使用验证。

时间节点排序仍使用事件编辑中的明确排序；直接拖拽改序属于后续交互优化。
