# 墨叽 · 小说工作台

## Windows 本机版

解压 `MoJi-0.10.1-windows-x64.zip`，双击 **启动墨叽.cmd**。不需要安装 Node、npm、Git 或 Auth0。启动后在默认浏览器使用工作台。

作品自动保存在 `%LOCALAPPDATA%\MoJi\workbench`。程序目录与作品目录分开；换新版前先在“作品与备份”导出完整备份，确认保存后关闭页面、双击“停止墨叽.cmd”，再打开新版。删除程序目录不会删除作品目录。

本机 MCP 地址是 `http://127.0.0.1:43127/mcp`，适用于允许连接本机 HTTP 的客户端。ChatGPT 云端连接需要下面的个人云端版。本机版不会自动与云端版同步；迁移使用完整备份导入。

包内包含官方 Node.js 24.22.0 LTS、完整前端、工作台引擎与相关许可。不包含作者作品、登录凭据、浏览器数据或开发环境。

## 个人云端版

发布源码后，项目首页的 **部署到 Cloudflare** 按钮会引导创建你自己的实例。

1. 登录自己的 Cloudflare 与 GitHub 账号，确认复制项目。
2. 为 `MOJI_OWNER_KEY` 设置一个自己保管的随机密钥，至少 24 位。它只用于你自己的实例，不需要交给墨叽作者。
3. 保留默认部署设置。数据库、授权存储、作品运行实例由模板创建，数据库结构由部署脚本初始化。
4. 部署完成后打开 `workers.dev` 地址，把页面显示的 `/mcp` 地址添加到聊天客户端。连接时输入刚才的密钥并确认授权。

不需要 Auth0 租户、应用、Client ID、Client Secret、回调地址或手动创建数据库。Cloudflare/GitHub 的账号授权仍由你确认，资源和可能产生的费用属于你自己的账号。

这是个人实例，不开放公共注册。密钥缺失、使用示例值或太短时，服务保持关闭，访客无法抢先绑定作者。

## 自动续期

内置授权使用 Cloudflare 官方 `@cloudflare/workers-oauth-provider` 1.2.3：PKCE 授权码、动态客户端注册、短期访问令牌和轮换刷新凭据。访问令牌有效 1 小时；刷新凭据最近使用后保留 365 天，每次刷新延长闲置期限。客户端注册不再因为默认的 90 天 TTL 自行失效。

无需靠刷新网页或定时访问来“保活”。符合 OAuth 刷新流程的客户端可以在访问令牌过期后续期；如果客户端本身不执行刷新、用户主动断开、凭据被撤销或超过一年未使用，仍需重新连接。

授权页需要输入实例密钥、确认连接方和回调地址；有浏览器绑定的一次性授权表单、同源提交检查和持久化的登录尝试限制。密钥不放在 URL、安装包或源码里。

## 已有 Auth0 实例升级

已有私有配置继续走原来的 Auth0 验证，更新代码不会自动切换登录或创建空作品库。

经实例拥有者确认后，给原 Worker 增加 `OAUTH_KV` 和 `LOGIN_GUARD`，设置 `MOJI_AUTH=builtin` 及自己的 `MOJI_OWNER_KEY`。必须保留已有 `OWNER_SUB`、原 D1 和 `WORKBENCH_RUNTIME` 绑定。旧的 `AUTH0_ISSUER`、`MCP_RESOURCE` 可以先保留用于回退，内置模式不使用它们。

切换授权服务器需要客户端重新连接一次；旧 Auth0 刷新凭据不能直接转换成另一家签发的凭据。保留原配置时，旧客户端的已签发 Auth0 访问令牌仍经过原有签名、期限与作者校验，以便逐步过渡；新的发现与登录使用内置授权。新连接继续使用同一个 `OWNER_SUB` 访问原作品。回退时恢复 Auth0 模式，不修改 D1 内容。
