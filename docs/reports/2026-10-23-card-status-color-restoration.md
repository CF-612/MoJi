# 2026-10-23 · 剧情卡状态色与伏笔关联标记恢复

## 本阶段范围与授权

依据用户最新反馈恢复“讨论中／准备采用／已写入正文／暂不采用”的卡片颜色；时间线共用同一套规则，关联伏笔的卡片另外区分。只改显示，不修改剧情卡、伏笔、章节或时间位置数据。仍须先看预览再提交推送；本阶段未 staging、commit、push 或部署。

## 问题证据

- 旧卡片主题 CSS 对 `.scene-card` 生效，统一画布改用 `.u-canvas-card` 后没有承接状态色。
- 叙述时间线使用 `domain/story-presentation.mjs` 固定色，而不是用户设置生成的 `--card-*`。
- 故事时间线卡片没有状态色绑定。
- 真实伏笔关联位于 `writing.foreshadow.list` 返回的 `plotNodes[].cardId`，不能根据卡片标题或用途猜测。
- PNG/SVG 原导出把首张卡片背景当作所有卡片背景，需同时修复，否则预览颜色与导出不一致。

## 实际修改

1. 新增 `shared/planning-card-presentation.mjs`，统一状态归一化、真实关联 ID 集合、可读 title/ARIA 标签和卡片样式。
2. 画布、大纲、叙述时间线、故事时间线及两处待安排卡片绑定同一套属性。
3. 使用已有用户 `--card-idea/selected/written/dropped` 配色；状态色体现在整卡淡色底及左侧色边，不再只有小圆点。
4. 保留默认主题的正文颜色，淡底与 `--cg-paper` 混合，因此随昼夜主题变化，不把任意用户色直接用作文字色。
5. 关联伏笔时叠加轻微紫色底与双线右边，不覆盖左侧状态色；标题/辅助技术标签同时说明“关联伏笔”。暂不采用保留虚线边框，避免只靠颜色区分。
6. PNG/SVG 从每张真实 DOM 卡片读取背景、状态边、关联边及虚线状态；导出保留逐卡差异及可读 SVG title。路由几何/API 未改动；导出不追求复制所有装饰渐变像素。
7. 与时间线编辑/布局代理协作：对方负责资源加载、两时间线 JSX 绑定与布局，本代理负责共享样式、画布/大纲属性及导出。
