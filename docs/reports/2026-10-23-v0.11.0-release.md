本轮从已公开的 `0.11.0-v31.5` 源码恢复，重建并重新验证了两项未提交修复：

## 包体与安全边界

本次发行提供三个用途不同的包：

- `dsh-moji-0.11.0.tgz`：DSH 原生插件。
- `Moji-0.11.0-windows-x64.zip`：Windows x64 独立工作台。
- `Moji-0.11.0-plugin-generator.zip`：离线个人插件 ZIP 生成器，不是直接可上传的插件包。

Windows 包使用 Node.js 官方 `v24.19.0` Windows x64 运行时，已按官方 SHASUMS 校验 SHA-256：`3602f2bb1a10f2cbab4c36886218a33c1ab3db87290e73b033c46c77147d0237`。包含原许可证与来源记录，不从第三方镜像取得运行时。

最终分发包需从明确允许的文件构建，排除私人交接材料、账号配置、密钥、实例清单及作品数据。各包最终校验值以同一 Release 的 `SHA256SUMS-0.11.0.txt` 为准；公开下载后另行核对文件与哈希。

## 未由本环境代替验收的内容

- Linux 包内服务测试不等于 Windows 双击启动、真实 DSH 安装及系统集成测试。
- 本地契约与 ZIP 测试不等于 ChatGPT 插件导入、OAuth 及 Codex / 网页 / 手机完整 GUI 验收。
- 用户反馈个人云端部署流程已经跑通；这不代表本轮新源码已部署到该实例。
- GitHub 推送、Release 发布与个人云端更新是三个独立步骤。云端更新必须复用原实例配置、数据库、授权存储与身份，不创建替代实例。
