# 0.11.0-v31.3 预发布更新

此预发布版本在 v31.2 的界面和 DSH 请求头修复基础上，补充个人云端部署安全检查、运行时兼容性及通用安装文档。预发布不代表真实云账号或全部宿主已验收。

- 部署执行器区分新建、更新与恢复，核对资源所有权、绑定和迁移阶段；使用锁定 CLI 适配层，避免自动供应资源或误接管同名资源。
- 增加就绪检查与受保护入口检查，完善个人 OAuth 和健康状态的测试覆盖。
- 精确锁定工作台 Wrangler 4.151.3 及正常解析的依赖；新增实际根配置测试，保持原兼容日期、flags、绑定与迁移设置，不降低日期绕过错误。
- 整理通用 DSH 安装/更新文档，将本地插件与个人云端部署分开说明，不包含私人账号、资源标识或设备路径。
- 保留 v31.2 的自定义关系颜色、资料图、故事时间、轨道、大纲及移动布局功能。

本轮版本准备前，干净安装验证已通过根测试376/376、工作台293/293、云端14/14；版本更新后的构建与测试结果另见发行验收记录。官方 DSH 请求头序列化回归不调用模型。

真实手机、真实 DSH 模型聊天、真实云账号部署及双端完整协作尚未在此构建环境验收；由使用者在安装和部署后确认。没有替用户登录或部署 Cloudflare。
