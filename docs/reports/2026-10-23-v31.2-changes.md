# 0.11.0-v31.2 候选版本更新

此版本替换 0.11.0-v31.1 候选安装包；仍为候选版本，不代表公开发布或云端部署。

- **DSH 关键修复**：为 `moji_structure` 补齐工具描述，并在注册前验证描述，避免 `undefined` 进入官方 `request/header` 导致严格 JSON 序列化失败。回归测试使用官方序列化路径，不调用模型。
- **关系字段与资料图**：支持每本书自定义关系名称、颜色与动态图例；重命名、版本冲突、在用删除保护、历史及备份兼容。资料卡四向连接、自然曲线避障、标签布局与导出保持一致。
- **故事时间与轨道**：日历优先的首次配置、可选剧情卡锚点、居中初始坐标、双侧刻度、视图游标、清晰的新建入口、缩放控件，以及直接改名、拖动排序和轴侧调整。首次事件预选当前时间并展开日期字段。
- **交互与移动布局**：关系预览支持收起、调整宽度、缩放和平移；大纲整行展开收起，并支持双击、右键或长按编辑。窄屏保留同一套功能，以切页和触控布局适配，不强塞桌面分栏。
- **设置**：修正响应式布局与缩放；模块默认启用，已有明确关闭设置继续保留。

验证包含根项目、工作台、云端自动化测试，以及云端浏览器的桌面与 390px 窄屏实际交互检查。未把窄屏浏览器检查称作真实手机测试，也未把序列化回归称作已安装 DSH 的模型聊天验收。
