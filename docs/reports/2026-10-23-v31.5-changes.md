# 0.11.0-v31.5 候选更新

本版为规划与大纲交互修复候选版，不替换正式更新渠道的 0.10.1，也不自动部署任何个人云端实例。

## 本轮改动

- 重新生成大纲时清理旧自动投影，同时保留手工画布内容、正文与剧情卡源数据；展示页面可删除，最后一页删除后保留空白画布。
- 规划画布与大纲支持多选、批量删除、移除本页展示、分组，以及组合为篇章。明确区分删除源卡与移除展示；保护正文卷章、未选子项和受伏笔引用的卡片。
- 独立自定义分组支持新建、改名、成员移入移出和删除，备份复制导入会重新映射成员 ID。
- Delete 键支持多选工具栏与大纲选框焦点，同时避免在文本输入、弹窗、输入法合成、忙碌状态误删；过滤或切换作品后清理失效选择。
- 修复触屏多选捕获与空分组提示，并调整设置入口顺序。

## 升级与验证边界

升级前请导出完整备份。新分组数据使用可选字段，不猜测迁移旧自由画布的 legacy 分组。源版本和安装包版本为 `0.11.0-v31.5`；源码提交、安装包哈希与发布状态由本次发行记录确认。

最终版本根测试 487/487、工作台 327/327、本地 Cloud 14/14 全部通过且无跳过；类型检查与根／工作台／Cloud 构建全部通过。专项测试覆盖批量事务回滚、冲突、撤销重做、持久化、导入引用重映射与键盘保护。预览验收不等于真实 Windows／DSH 安装、ChatGPT ZIP 导入与 OAuth、物理右键拖拽或手机输入法已验收。

Windows ZIP 是本地运行包，DSH TGZ 是插件包；plugin-generator ZIP 是可复用生成器源码，**不是可直接上传的个人插件 ZIP**。后者需使用本人实例地址离线生成，不能包含作者的私人地址、密钥或作品。个人云端仍需实例所有者另行更新并验证。
