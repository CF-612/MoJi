# 墨叽 0.11.5

- 紧急兼容 DSH 0.2.1-rc.3：修正宿主版本声明，保留已支持的旧版本；不使用兼容豁免。官方 rc.3 Linux 宿主实际加载打包插件，注册六项工具和六项技能；旧版本范围负控被正确拒绝。详见[兼容验证](../dsh-rc3-compatibility.md)。

- 修复时间线拖动后小数位置导致编辑保存失败。
- 验证催更姬 0.5.0 导出的整本作品包恢复、历史版本查看与恢复，保留回收站、分组、规划和装饰等备份数据。
- 旧规划作为明确标记的只读档案展示，不自动转换成统一情节卡。整本导出保留旧规划；局部规划导出只选择统一画布。
- 阻止暂不支持的多设定画布复用和可能破坏分组的数据操作。

## Agent 执行更新

- Codex 个人插件包生成器支持从现有 ZIP 保留应用身份生成更新 ZIP；随后由用户或获授权的 Agent 使用宿主界面在原插件上传新版本，不新增连接。
- DSH 提供 GitHub 官方包下载、校验、备份和安装的 Agent 执行脚本。需当前 profile 的新鲜人工核实预检、宿主已停止等条件；不满足时拒绝执行。
- 更新界面明确区分本机与个人云端；手机使用个人云端时，仍须授权更新原云端实例，保留原库及授权。
- 不声称宿主可无人值守安装；实际 Windows/DSH 安装操作未在本次 Linux 环境执行，覆盖为合成适配器测试与打包 runtime 验收。

## 迁移边界

先保留原库和整本备份，再恢复到独立墨叽作品库。不能直接打开催更姬 v5 数据目录，也不要手工改版本号降级。见[迁移指南](../cuigengji-migration.md)。这不是所有功能双向兼容的承诺。

安装包更新不等于个人云端更新；原云端需另行更新原实例。本次验证仅使用合成作品。
