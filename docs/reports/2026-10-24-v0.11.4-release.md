# 墨叽 Moji 0.11.4 发布记录

本次补齐作者原定的默认头像功能，而非以披露缺项代替交付。0.11.3 标签及已发布附件保持不变；新版本统一重新构建 DSH、Windows 独立版和插件生成工具。

## 完整交付范围

- 七款经确认的默认头像：成年男性、成年女性、老年男性、老年女性、男孩、女孩及兜帽中性；原始 PNG 随包提供，以稳定白名单 ID 保存，可离线使用。
- 选择器包括姓名首字、七款预设与自定义上传。选中只是草稿，明确保存后生效；取消、失败重试、刷新、旧自定义图片与备份恢复覆盖测试。
- 人物列表、资料画布、关系图、剧情关联头像及画布 SVG/PNG 导出使用同一解析方式。原始人物/作品内容不被头像操作改写。
- 自定义上传按钮美化；资料搜索移入更多，活动搜索有可清除入口；不显示错误的多选操作提示。
- 正文底部关联区更紧凑，高亮开关紧邻分类标题；标题使用实际对象数量，没有高亮依据的关联对象仍正常展示。

## 验证

最终 root **571/571**、workbench **339/339**、cloud **14/14**，合计 **924 项**，无失败、跳过或取消；类型检查与 DSH/workbench/cloud 三构建通过。完整测试日志与文件哈希保存在 `artifacts/stable-0.11.4/`。

已在云端 Chromium 的生产组件 fixture 中实际导出并下载七头像 PNG，逐一目视确认正常显示。覆盖选图保存、刷新、取消、自定义上传、键盘选择、窄屏和暗色布局。此为云端浏览器验证，不冒充原生手机或所有宿主客户端实测。

## 升级与边界

旧客户端不能解析新增头像预设 ID，因此使用同一作品库的客户端与个人云端都应更新对应软件代码；自定义上传的普通图片仍保留兼容。预设 ID 连同作品数据进入备份，原始静态头像随本次包体提供。

更新本地 DSH 包、下载源码或 Git push **不会自动更新个人云端**。云端用户须按[原实例更新说明](../cloud-agent-deployment.md#cloud-update)重新部署原实例，保留原账号、manifest、D1/KV、密钥和实例身份，然后刷新客户端。本次发布不执行 Cloudflare 部署。

产品版本为 0.11.4；插件品牌模板仍为 1.0.6。继续使用“创建自定义 MCP 并授权 → 在同一个插件上传更新 ZIP”的单入口流程。Gemini 仅网页端 MCP 内容读写，无工作台界面，手机端暂不支持；个人云端根地址不是独立网页版编辑器。
