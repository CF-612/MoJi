# 卡片时间线与人物关系演变更新

按作者确认的隔离预览实现连续横向卡片时间线，保留摘要、人物、状态、章节与伏笔标记；支持待安排、跨轨拖动、跨度调整、轨道与配色、重叠排布和统一缩放。

人物关系演变恢复到时间线下方，电脑默认展开，手机默认收起并保留明确入口。滑动条仅包含实际改变关系的关键事件，普通事件沿用最近阶段；可展开完整关系图。关系编辑继续调用原有编辑器。

正式安排使用作品内独立的 `timelineLayout` 字段，经 `timeline.layout.get/save` 保存，采用版本比较防止旧窗口覆盖。DSH 本机与云端共享同一命令引擎；整本备份包含该字段。拖动不写正文、章节引用或原文依据。隔离预览测试数据不会导入正式作品。

验证：六项卡片模型检查、三项关系阶段检查、正式磁盘跨实例与备份导入导出检查、真实 Worker 的 UI RPC 读写、DSH 会话与云端客户端回归、TypeScript 检查及前后端构建通过。浏览器验证了关系阶段从陌生切到朋友。真机触摸手感仍需作者实际体验。

云端使用现有实例和既有绑定，保留登录凭据。标准 Wrangler 部署列表接口返回无访问权限；已通过同一登录具备权限的脚本更新接口完成代码更新。`cloud/embedded-entry.mjs` 与 `scripts/build-cloud-embedded.mjs` 将同一份界面随代码构建，保留原资产绑定、密钥和数据库。

DSH 包已构建；本环境对用户 `.dsh/plugin-packages` 目录没有写权限，自动安装在复制候选包前失败，未更改 profile。用户可在自己的 PowerShell 执行 `scripts/update-moji-local.ps1` 完成原地安装；脚本先备份配置、保留旧包，核对其他插件不变，不自动重启宿主。
