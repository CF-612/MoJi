# 墨叽 MoJi 0.12.0

这次更新主要做了三件事：让开始写作更清楚，让界面更尊重宿主环境，也为越来越长的故事整理了存储底座。

## Bug修复

- **不再干扰 DSH 的壁纸与主题。** 墨叽的背景、弹窗和样式限定在自己的界面内；打开、切换主题或关闭工作台，不应改变宿主的背景设置。
- **改善手机和窄侧栏的欢迎页。** 调整图文与新建表单的排列，避免拥挤、重叠；主要操作保留清晰的蓝色按钮。
- **菜单与宿主能力一致。** Codex 等没有本机连接功能的宿主优先显示「设置」，不再放置无用的连接入口；DSH 仍保留连接能力。
- **校正 AI 修改指引。** 工具说明改用当前统一剧情接口，明确版本冲突、重复请求和正文依据的边界，不再引导 AI 调用已停用的旧事件动作。

## 架构更新

- **剧情和结构资料按实体、当前值与历史分片保存。** 日常剧情读取按需要加载，不再连带读取整本正文和全部历史；完整导出、恢复等操作仍进行完整校验。
- **旧墨叽作品库带备份迁移。** 新本地格式明确命名为 `moji-library` v5，支持旧单文件及 v2/v3/v4 库迁入；保留稳定 ID、引用、顺序、精确时间值、历史和额外字段。迁移前检查并备份，中断可恢复；损坏或未知格式停止处理，不以空库掩盖问题。
- **云端大库减少重复存储和重写。** 新分片编码保留旧编码与历史快照的读取。D1 仍完整加载工作库，本次不宣称已经实现云端按操作懒加载。

## 新增内容

- **更简洁的空库欢迎页与新建作品体验。** 保留烟灰蛸图标，突出开始写作、导入和恢复入口；新建表单支持封面选择，并补充像素封面的说明。
- **可跳过、可重开的页面引导。** 标准配置下用 10 步认识工作台，最后带到实际设置入口；可从帮助中重新打开。引导只介绍和导航，不替作者开启功能、创建示例作品或修改正文。
- **规划入口更直观。** 默认打开画布，将原「白板」明确命名为「多页画布」，标准预设保留总览；已有显式关闭偏好继续保留。
- **给 AI 和开发者的功能扩展指南。** 新增实际代码入口、最小功能示例、兼容与验证清单；想法可以先提 Issue，也欢迎自行实现后提交 PR。当前是仓库内扩展流程，不是第三方插件 SDK 或创意工坊。

## 升级注意事项

1. **先导出完整备份并保留原库。** 新版迁移后的物理库不能直接交给旧版打开，也不能手改版本号降级。确需回退时，先保留升级后的新写作，再在独立目录恢复升级前备份。详见[更新与回退](https://github.com/CF-612/MoJi/blob/moji-v0.12.0/docs/upgrade.md)。
2. **墨叽 v5 不等于催更姬 v5。** 继续支持催更姬 0.5.0 导出的可移植完整作品包，不直接打开其原始 v5 数据目录。旧规划只读保留、完整备份继续携带，不自动转换为统一剧情卡；这不是所有功能双向等价的承诺。详见[迁移边界](https://github.com/CF-612/MoJi/blob/moji-v0.12.0/docs/cuigengji-migration.md)。
3. **个人云端需更新原实例。** 下载新包或更新源码不会自动更新云端；使用原账号和原资源重新部署并核验后，手机等客户端才会使用新版。不要另建空实例代替原库。个人插件生成器用于生成更新 ZIP，本身不是可直接上传的成品插件。

附件提供 DSH 原生插件、Windows 本机版、个人插件包生成器及 SHA-256 校验文件。验证使用合成作品；本次未在真实 Windows 桌面执行安装验收，也未替任何作者部署个人云端。
