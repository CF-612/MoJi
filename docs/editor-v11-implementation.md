# 编辑器 V1.1 实施说明

本轮复用原有章节同步、草稿缓存、版本历史、备份与服务端查找替换，不新增云存储或富文本模型。实际工作台代码在 `integrations/chatgpt-workbench/vendor/cuigengji/src/client/`。

## 交互与安全边界

- 查找改为正文内两行工具条。完整匹配索引来自眼前草稿，使用 textarea 的 UTF-16 偏移；预览片段不参与计数或导航。透明镜像层显示全部匹配，当前匹配单独强调。关闭后将原选区映射到当前文本并恢复滚动位置，不拆掉选区关联资料能力。
- “当前”替换仅修改草稿；“本章 / 全书”先保护本机作品的待同步草稿，预览章节、数量与替换前版本，再由作者确认。调用既有服务端指纹校验与稳定请求 ID；结果不明时重试同一次请求。确认前重新检查草稿，不静默覆盖其他窗口的未保存内容。
- 批量替换的恢复单位是**逐章历史版本**，不是一键整批撤销。完成后列出各章原版本；历史恢复走 P0 的先保护当前稿流程。服务层事务与失败回滚由独立批量安全测试覆盖。
- 四种复制使用当前草稿：标题＋正文、仅标题、仅正文、无空行正文。最后一种只滤除空白行，非空行缩进及内容保留。宿主拒绝剪贴板访问时提供可手动选择的文本，不报告虚假成功。
- 字体及布局仅改变显示；正文排版必须明确点击才改变文本。一次文本操作撤销仅在正文仍等于操作结果时提供；继续写作后不让旧全文覆盖新稿。
- 字数默认包含标点、不计空白；可改为同时不计标点与符号。仪表盘统计口径不变。
- 任意两版历史比较复用 TextDiff；只读比较与恢复操作分开。

## 偏好与持久化

- 设备 / 浏览器：字体、字号 14–32px（默认18）、行距 1.3–3（默认1.95）、颜色（自动适配主题）、字重、斜体、下划线、字距、标题对齐/隐藏、桌面和窄屏边距、额外底部空间（至少16px）、底部信息栏、标题栏透明、字数口径、打开章节末尾、快捷输入与时速开关。
- 原有宿主顶部、底部聊天框与系统安全区仍独立保留。隐藏信息栏不隐藏保存失败、冲突与未保存提示。
- 背景模糊默认关闭，在“设置 → 其他 → 背景效果”开启；遮罩始终保留。
- 快捷短语按作品和现有 SessionScope 保存在本机浏览器；不假装跨设备同步。支持增改删、拖动与上下移按钮；成对中文标点将光标放在中间。搜索或输入法组词时收起，只面向正文焦点。
- 码字时速只保存在当前页面会话，按作品累计，切章保留、刷新重置。正文输入启动，30秒无输入记空闲，20分钟后暂停；切后台或离开编辑器暂停。净新增不含空白、含标点；粘贴单列不计手写速度；删除扣减，已知撤销/重做恢复归属，同长度反复修改不刷速度。前一分钟以一分钟作速度分母。排版、替换、历史恢复、远端加载不计输入并重新建立该章基线。IME 中间拼音不计，最终提交一次。
- 手机方向只在移动/触屏环境提供；只有宿主 API 真正接受才显示锁定成功，不支持或拒绝时提示使用系统设置。

## 分享与备份

长图读取当前草稿或打开面板前的选区快照，标题可选、两种字体与基础字号。按字素换行，分页为1080px宽、每页最多3600px高；按需渲染和释放图片，不生成超大长画布，不改正文。逐页下载 / 系统分享受浏览器与宿主能力限制。

“整本备份”只是原有导出预览的快捷入口，使用 `works` 范围和既有 P0 草稿屏障；不新增自动云备份系统。
