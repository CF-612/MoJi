# 规划画布与大纲：生成、分组及删除修复阶段报告

日期：2026-10-23。范围：本轮用户反馈的规划交互与数据安全，不包含云端部署或发行包上传。

## 已修改的行为

- 重新生成大纲只保留本次自动生成的投影。清理旧独立自动页或主画布中的旧自动展示；保留手工页面、手工添加的展示、正文卷章和剧情卡源数据。确认框说明清理范围，规划历史可撤销。
- 所有画布页面均可删除。删除的是展示页面，不删除剧情卡、正文或关联关系。最后一个页面删除后保留一个空白“自由构思”页面，避免工作台无可用页面。
- 大纲多选可批量删除剧情卡／篇章。正文卷与章节不可删除；混选时显示保护数量和实际可删数量。只删除明确选中的卡，不级联删除未选子项；删除篇章后原子项上提。
- 画布增加多选、全选、批量删除、移除本页展示、加入分组和组合为篇章。右键菜单使用当前选择集。删除源剧情卡与仅移除展示明确分开。
- Delete 在画布、其多选工具栏以及大纲选框上生效；文本输入、编辑页、弹窗、输入法合成和忙碌状态不会误删。切换页面、作品或大纲搜索会清理旧选择；过滤隐藏的卡不会进入删除请求。
- 真正的自定义分组与包含层级的“篇章”分开：支持新建、改名、删除、移入／移出分组，以及“全部分组／未分组／指定分组”查看。关闭分组模块只恢复显示全部，不清空分类。删除分组保留所有成员和原包含关系。
- 新分组没有成员时，明确提示切换全部分组加入卡片，不再错误提示“内容在视野外”。
- 手机多选触控保留实际点击的卡片，不再受指针捕获影响错误操作已选列表第一张卡。

## 数据与接口保护

- 批量删除通过一次 `story.apply` 提交，完整引用保护与版本冲突检查仍有效。伏笔引用阻止其中一项时整批不写入，不出现半批删除。
- 删除确认使用打开确认时的 revision；确认期间另有修改会冲突而不是覆盖新数据。
- 自定义分组使用可选 `story.groups`，旧数据缺失时视为空。备份复制导入会重新映射分组及成员 ID，保留目标作品既有分组；局部导出依照有效引用清理成员。
- 新操作包括 `card.deleteMany`、`page.delete`、`page.outline.remove`、`instance.removeMany`、`group.create/rename/assign/delete`。原 `group` 表示包含层级的篇章，语义未混用。
- 不对旧版自由画布的 legacy `planning.groups/groupId` 猜测迁移：其卡片标识与当前共享 story 卡片并不保证一一对应。本轮保证当前共享规划的新增分组可靠持久化，不声称已迁移旧分类。
