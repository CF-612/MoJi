# 墨叽 · 小说工作台

**陪你写故事的烟灰蛸小说工作台。**

墨叽是围绕正文、自由画布和人物世界资料构建的小说工作台，提供本机版、个人云端部署及 [DeepSeek Harness（DSH）](https://github.com/deepseek-ai/deepseek-harness) 插件适配。你可以写正文、整理设定、用卡片和连线规划情节，再与聊天客户端里的 AI 一起讨论、续写和修改。

[安装与个人云端部署说明](docs/moji-installation.md) · [原版项目](https://github.com/mistnest/dsh-cuigengji-plugin) · [墨叽现版项目](https://github.com/CF-612/MoJi)

[下载 Windows 免安装版](https://github.com/CF-612/MoJi/releases/tag/moji-v0.10.1) · 源码发布分支：`moji-release`。


它想解决的是长篇创作里的一个常见问题：**AI 能写出一段像样的文字，却未必知道你整本书想怎么写。** 人物为什么沉默、哪条伏笔还不能揭开、下一章要走向哪里，这些往往都在正文之外。

## 正文之外，也有故事

一部小说可以比作一座冰山。正文是读者看见的部分，水面之下还有人物动机、世界规则和作者对后续情节的安排。

墨叽把这些创作资料放在同一本作品里，并给 AI 提供查阅和维护它们的工具。写到某个人物时，可以查他的设定；讨论下一步时，可以查看规划；续写时，可以回到相关正文。你和 AI 面对的是同一份作品资料，讨论也能留下来，供下一次继续。

我们的设计思路很简单：

- **正文是基础。** 已经写下的故事，是前后连贯的依据。
- **规划是可以一起讨论的路线。** 用节点、连线和批注整理后续情节，保留尚未决定的走向。
- **设定是随时可查的案头资料。** 角色卡、世界书、分组和关系图帮助理解人物与世界。
- **故事由作者做主。** AI 是写作助手，你可以直接修改正文、设定和规划，也可以调整写作要求。

这些信息按需要查阅，不会每次把整本书和全部资料塞进对话。目标是减少长篇写作中的人物变味、伏笔断掉和情节跑偏，让墨叽更贴近你的故事与想法。

## 你可以用它做什么

### 接着写正文

按卷和章节整理作品，目录里直接看每章字数，不用时收起。打开章节就能编辑，修改自动保存；粘贴进来的文字可以一键排版，也能复制到 Word、WPS 或发布网站。需要回看时，可以查看和恢复历史版本。

### 一起推敲下一章

每个规划节点都有标题、摘要和自由正文。拖动卡片安排位置，拖动连接点串起情节；连线可以取消和删除。还没想好的问题留在文字批注里，新支线可以单独开一页。作者和 AI 都能维护这张图，逐步把讨论变成清楚的推进方向。

### 整理人物与世界

角色卡和世界书支持分组、搜索与关系图。人物之间是什么关系，某个地点有哪些规则，都可以随时查看、补充和修改。已有酒馆角色卡或世界书，可以导入后继续整理。

### 让写作要求跟着作品走

把文风、视角和其他写作要求放进预设，启用后提供给绑定这本作品的 AI 会话。支持导入酒馆提示词预设，重点保留提示词内容；具体导入范围见[角色卡与世界书说明](docs/tavern-import.md)和[预设说明](docs/presets.md)。

### 把作品带走

正文、版本历史、设定、规划和预设都存放在独立的小说工作数据目录里，可以导入、导出和备份。升级插件或更换源码目录，不需要把小说混在代码里。

## 先试用，再安装

如果想先看看界面，安装 Node.js 24 或更新版本，执行：

```powershell
git clone https://github.com/mistnest/dsh-cuigengji-plugin.git
cd dsh-cuigengji-plugin
npm ci
npm run preview:workbench
```

打开终端返回的本地地址即可。预览会创建一份临时演示作品，可以自由操作；想留下试用内容，请从作品菜单导出。这个预览用来体验工作台，和 AI 协作需要安装到 DSH。

当前主要适配 DSH Windows 桌面版，已验证的宿主版本是 **0.2.0-rc.2**。普通用户直接使用 [0.4.0 发布包](https://github.com/mistnest/dsh-cuigengji-plugin/releases/tag/v0.4.0)，无需安装 Git；桌面安装步骤见[安装与开始使用](docs/getting-started.md)，更新和自动迁移见[更新与数据迁移](docs/upgrade.md)。

安装后，从 DSH 左侧栏的 **墨叽** 进入。创建或选择一本作品，再在绑定这本作品的会话里讨论写作；空白会话也能打开工作台。

## 你的小说与你的代码分开

这个公开仓库只提供插件源码、使用文档和测试用的合成样例，**不附带作者的小说、私人设定、聊天记录或工作数据备份**。

自己的作品请通过工作台管理，实际保存位置可在“导入 / 导出”中查看。可以选择作品、章节、设定分组、规划页或预设，也能备份整个工作库，详见[导入与导出](docs/import-export.md)；DSH 的聊天记录、附件与账号配置由 DSH 管理，需要另行备份。

## 一位随时可以讨论的写作搭档

就像给自己配了几位随叫随到的编辑：一起琢磨人物，讨论情节，推敲下一章怎么走。正文、设定和规划，就是共同翻阅的案头资料。这是创作体验的比喻，插件本身不内置多个独立编辑 Agent。

AI 的理解和写作能力仍取决于你在 DSH 中选择的模型以及作品资料的质量。墨叽提供共同创作的工作台，让讨论有依据、结果能留下来；最终方向和采用哪些内容，由你决定。

**故事由你做主，墨叽陪你写下去。**
